# 🌸 Vườn Hoa 20/10 - Dành Tặng Người Phụ Nữ Tuyệt Vời

Trang web vườn hoa nở rộ lãng mạn mừng ngày **Phụ nữ Việt Nam 20/10**, được xây dựng bằng HTML5 Canvas, Vanilla CSS (Glassmorphism) và JavaScript tối ưu hóa 60-120 FPS.

## ✨ Tính Năng Nổi Bật

- **Vườn hoa Canvas sống động:**
  - Hoa nở đa tầng (Hoa hồng, Mẫu đơn, Tulip, Cúc đồng nội...) với bảng màu pastel rực rỡ.
  - Hiệu ứng vật lý gió lay mềm mại, phản ứng tự nhiên khi lướt chuột qua.
  - Chạm / click bất kỳ đâu trên màn hình để gieo hoa theo ý muốn.
  - Cánh hoa rơi bồng bềnh, bướm bay lượn và hạt phấn phát sáng.

- **Thiệp chúc mừng Glassmorphism:**
  - Khung ảnh Polaroid kỷ niệm (hỗ trợ đổi ảnh trực tiếp từ máy).
  - Lời chúc hiển thị theo hiệu ứng máy đánh chữ (Typewriter).
  - Tùy biến người nhận, người gửi và lời chúc dễ dàng.

- **Âm nhạc lãng mạn:**
  - Nhạc chính: *Stephen Sanchez - The Pool* (bản tình ca acoustic ngọt ngào).
  - Kèm các bản Piano kinh điển (*Chopin - Nocturne Op. 9 No. 2*, *Debussy - Clair de Lune*, *Canon in D*).
  - Hỗ trợ đổi bài hoặc tải nhạc riêng từ máy tính (.mp3).

- **Tạo Link Tặng Riêng Biệt (Dynamic URL Sharing):**
  - Chỉ cần 1 trang web deploy lên Vercel là có thể tạo vô số đường link riêng biệt cho từng người (Mẹ, Người yêu, Chị em, Bạn bè...) thông qua tham số URL.

- **Chụp ảnh tải thiệp:**
  - Tự động xuất ảnh vườn hoa kèm khung thiệp lời chúc độ phân giải cao dạng PNG để gửi tặng qua mạng xã hội.

## 🚀 Triển Khai Lên Vercel

Dự án là trang web tĩnh (static web), sẵn sàng deploy lên Vercel chỉ với 1 cú click:
1. Kết nối repository này với Vercel.
2. Bấm **Deploy**.
3. Chia sẻ đường link tới những người phụ nữ bạn yêu thương!
